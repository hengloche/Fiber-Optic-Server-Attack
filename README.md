# Fiber-Optic-Server-Attack



Fiber Optic Server Attack

Step 1: Obtain the authentication information of the fiber optic leased line between the national telecom operator and the enterprise.

Step 2: Organize personnel to add a server between the operator and the enterprise's fiber optic leased line. After authenticating with the operator, directly send data to the enterprise's intranet to retrieve data. (Requires two components: an authentication box similar to an optical modem and a fiber optic switch.)

By using the same fiber optic cable, whitelist filtering can be bypassed. Solar panels are needed to power the server and switch. Fiber optic cable splicing is required.
